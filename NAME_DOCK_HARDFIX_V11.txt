V11 HARD FIX

Problem:
The moving VAHRAM TUMANYAN element was still inside the HERO DOM tree.
A fixed-position element can be constrained by ancestor stacking/containing contexts,
which can make it look like it remains lower than the sticky header.

Fix:
- The SAME name element is detached from HERO and appended directly to <body>.
- It is rendered as a true viewport overlay.
- On scroll it moves and shrinks to the absolute top beside the round avatar.
- It has a z-index above the sticky header.
- No duplicate name and no fade swap are used.
