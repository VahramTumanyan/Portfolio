V50 — BASED ON V49

PRIVATE ARCHIVE VIEWER ZOOM / NAVIGATION FIX

- maximum zoom increased from 2.6x to 6x
- mouse-wheel zoom step increased slightly for faster zooming
- single click/tap quick zoom now goes to 2.15x
- after dragging a zoomed image with the mouse, it stays exactly
  where the user released it
- after moving a zoomed image with a finger, it also stays there
- the browser's click-after-drag no longer resets the zoom
- touch pan no longer causes an accidental tap-to-reset
- pinch gesture no longer causes an accidental reset when fingers are released
- zoom/pan resets only when the user intentionally toggles zoom off,
  changes image, or closes the viewer

Everything else remains V49.
V47 / V48 / V49 remain safe fallback versions.
