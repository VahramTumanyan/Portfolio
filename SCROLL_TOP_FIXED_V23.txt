V23 — BACK TO TOP FIX

Cause of V22 bug:
- script.js was loaded before the Back-to-Top button existed in HTML
- JavaScript searched for #vtScrollTop, got null, and exited
- therefore the button could be visible but had no click action

Fix:
- button now exists before script.js loads
- JS also waits for DOMContentLoaded as a second safety layer
- click scrolls the actual document scrolling element to top
- arrow is drawn in CSS, no image file needed

No other site behavior was changed.
