FIXED SQUARE CARDS V1

Both portfolio card groups now use the exact same fixed square size:

- ANIMATION cards: 320 x 320 px
- WORK cards: 320 x 320 px
- WORK remains in two rows
- cards no longer stretch or become rectangular when the browser/window width changes
- if there is not enough space, the carousels scroll horizontally instead of shrinking the cards

Note:
Browser zoom itself scales the whole webpage, which browsers always do.
But the card proportions and CSS dimensions remain fixed and square.
