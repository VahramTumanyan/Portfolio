VAHRAM PORTFOLIO — DIRECT BEHANCE CDN VERSION

This version keeps the large Photoshop-style design.

The project images are loaded directly from the same Behance CDN used in the first prototype:
mir-s3-cdn-cf.behance.net

No manual local artwork replacement is required for these demo projects.

Current direct-image projects:
- Cartoon Bird of Prey
- Spine 2D Environment Art
- Flying Crocodile
- Dieselpunk Beetle
- 2D Games Environment Design
- Frog on a Cloud
- Environment Art + Character Design

How it works:
1. Layers shows the actual Behance CDN thumbnail.
2. Click a Layer.
3. The same artwork opens large inside the Photoshop canvas.
4. Mouse wheel zooms the canvas.
5. Drag with mouse to pan.
6. Fit and 100% buttons still work.
7. Behance button opens the exact project page.

One interactive fly remains.
