SPINE CHARACTERS TEST V1

Это отдельный тест без портфолио и без Behance.

Логика:
- Муха: летит только слева направо, при этом мягко двигается вверх/вниз. Никаких случайных прыжков по экрану.
  Используются реальные Spine: flies / flies_Run / fire / Rig_View.
  Клик по мухе -> fire.
- Лягушка: крупная справа внизу. Используются fire / Rig_View.
- Крокодил: вдоль нижней части экрана слева->направо->обратно.
  running + случайный Happy_1/Happy_2, start в конце цикла.
- Все тумблеры и кнопки сверху, компактные.
- Все персонажи изначально выключены.

Для проверки загрузите папку на GitHub Pages или запустите через локальный HTTP server.
