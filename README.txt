SPINE CHARACTERS TEST V1.2

Изменения:
- Крокодил развернут ещё раз по фактическому направлению его рисунка, чтобы не ехал задом.
- Муха тоже разворачивается по направлению движения.
- Муха снова свободно летает по всему экрану: влево/вправо/вверх/вниз случайными маршрутами, но без телепортов.
- Для далёких перелётов муха использует flies_Run, для обычных — flies.
- Клик по мухе запускает настоящий fire, затем она продолжает полёт.
- Лягушка стала заметно крупнее и расположена ближе к центру нижней части экрана.
- Rig View для любого персонажа теперь открывается очень крупно по центру экрана на затемнённом фоне, чтобы хорошо рассмотреть детали рига.
- В Rig View используется настоящая Spine-анимация Rig_View.
- Сайт/Behance по-прежнему не добавлены: это только тест персонажей.
