VAHRAM PORTFOLIO — SPINE VERSION 2

1) Upload the ENTIRE contents of this folder to your GitHub Pages repository.
2) Keep the assets/spine folder structure unchanged.
3) Do not test by double-clicking index.html with file:// because browsers often block JSON/atlas loading.
   Test on GitHub Pages (recommended) or any local HTTP server.
4) Spine runtime is loaded from UNPKG, version 4.3.13, matching exports from Spine 4.3.x.

Character logic:
- Fly: ON by default. Auto plays flies / flies_Run. Click the fly to play fire. Rig_View is manual.
- Frog: fire and Rig_View only. Turning it ON shows it in the center, it fires, then disappears.
- Crocodile: Auto = start -> running -> random Happy_1/Happy_2 -> repeat. Rig_View is manual.

Behance work cards use direct Behance CDN thumbnails and link to their project pages.
