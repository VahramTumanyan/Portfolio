FLY TOGGLE LOCAL PREVIEW V1

Only this was changed:
- The old top-right BEHANCE position now contains one new FLY ON/OFF switch.
- The switch design is dark, slightly hand-drawn, and uses the site's muted yellow accent when ON.
- The interactive Spine fly remains fixed while scrolling.
- Click the switch to hide/show the fly.
- The fly itself remains interactive: hover = flies_Run, click = fire, normal = flies.
- All other site sections, cards, navigation, PRIVATE ARCHIVE, viewer, links and layout are unchanged.

HOW TO PREVIEW:
1. Extract the ZIP.
2. Double-click OPEN_SITE_LOCAL.bat.
3. Browser opens http://localhost:8000
4. Keep the black command window open while testing.
